## 安装

| 方式 | 步骤 |
| --- | --- |
| **Chrome 应用商店（推荐）** | 前往[商店页面](https://chromewebstore.google.com/detail/feedsieve/amhdjglnonjaoenddnifpnljgmocfdph)点「添加至 Chrome」，自动接收更新 |
| **GitHub Releases** | 从 [Releases](https://github.com/realchendahuang/feedsieve/releases) 下载 `feedsieve-*-chrome.zip` 解压 → `chrome://extensions` 开「开发者模式」→「加载已解压的扩展程序」 |
| **从源码构建** | `pnpm install && pnpm build:extension`，加载 `apps/extension/.output/chrome-mv3`（Node ≥ 22，pnpm） |

Edge / Brave 等 Chromium 浏览器同样推荐直接用上方商店版：Edge 首次访问商店页面时允许「来自其他商店的扩展」即可安装，自动同步更新（无需单独上架 Edge Add-ons）。装好即用，无需注册任何账号。

## 上手四步

1. **刷 X，看黄框** — 打开 [x.com](https://x.com) 正常滚动。高置信垃圾账号被**黄框**标出，下方一行显示判定的证据来源，内容本身不隐藏。
2. **单个送走** — 黄框上点「顺手拉黑」：走你已登录 X 会话的内部 Block 接口，与手动点屏蔽同一条请求，手机端即刻同步消失。
3. **攒一批一起送走** — 黄标账号自动进**待拉黑列表**（持久，可增删）。点弹窗里的「一键拉黑 N 个」逐个执行：成功即移除，失败如实保留并显示原因（额度用尽 / 限流 / 官方暂停分开提示）。
4. **漏网的自己补** — 在任意推文操作栏或扩展弹窗点「标记垃圾并拉黑」。不需要先理解任何检测规则，你的动作本身就是最高质量的判断。

**误伤了？** 已拉黑列表里点「放回来」一键撤销；页面上点「误标？」把账号加入本地白名单。误标不会进入社区批量候选——社区名单要求至少 3 个独立账号各投一票才生效。

识别的判断分层（用户动作 > 社区名单 > 本地弱证据）与数据流向的完整描述，见 [`ARCHITECTURE.md`](ARCHITECTURE.md)。

## 打野排位

弹窗新增「打野」一级 tab，把清理过程变成公开排位：

- **战报**：本周击杀、命中率、子弹余量、百分位与称号徽章。
- **榜单速览**：弹窗内直接看 Top 10 与你自己的排位（始终置底显示）。
- **完整周榜**：公开网页，纯观看，[feedsieve.win/lists/ranked](https://feedsieve.win/lists/ranked)。
- **想露脸？** 上榜默认匿名；在弹窗「我的」页认领档案并完成邮箱验证才参与公开署名，可自愿绑定 @handle。

计分口径：**确认击杀 +1**（账号收敛为共识黑名单成员且你当前仍投拉黑票时结算）、**首杀 +1**（同一赛季内最早上报者）、**误伤 −2**（票项被翻案或转入维护者白名单）。按共识击杀而非拉黑数量计分，刻意防止误拉黑刷分。周赛季 ISO 周结算，Top 3 且命中率 ≥80%、开火 ≥10 发获永久称号「猎黄人」。完整规则见 [`HUNTING.md`](HUNTING.md)。

## 设置项逐条

- **同步关注列表** — 把你的关注存为本地私有保护名单，自动排除在一切清理之外，永不上传社区。这是防止误伤自己人的一票否决金牌。
- **关键词规则** — 官方行业词库包（当前 8 组 778 条，以[官网词库 Tab](https://feedsieve.win/lists/keywords)实时计数为准），默认只开启「黄推 / 成人引流」，其余按需订阅，可整包或逐条关闭，也支持添加自己的词。收录边界与来源见 [`research/KEYWORD_PRESETS.md`](research/KEYWORD_PRESETS.md)；官方词库全量公示在[官网词库 Tab](https://feedsieve.win/lists/keywords)，与扩展执行的规则同源同版本。
- **识别强度** — 清爽 / 标准 / 大扫除 三档。档位只调"用多少证据"，不调"下手多重"：黄框标注在任何档位都绝不擅自自动批量拉黑，弱证据只在「大扫除」档提示人工复核。悬停设置项可看各档证据范围。
- **备份与迁移** — 导出 JSON，在新设备预览后合并或替换。导出不含任何 X 登录态，凭据只在你浏览器里。
- **个人白名单** — 页面点「误标？」加入的账号优先级最高，一票否决一切检测来源。

## 批量拉黑的安全边界

FeedSieve 走的是你已登录会话的内部 Block 接口，与手动点屏蔽是同一条请求。推特官方天天治不了满屏水军，但对正常用户拉黑频次抓得比谁都严。社区实测约每天 400–500 个之后容易被要求验证或强制登出。因此：

- 队列内置 **400 发子弹 / 24 小时**滚动额度，额度用尽自动暂停并提示；点「仍要继续」可放行本轮，但连续硬打会把临时锁定拖长。
- 连续 429 触发**风暴降级**：暂停 + 预算砍半；认证失效当天额度清零，随后逐日恢复。
- 成功间隔按注入节奏加抖动，不做固定节拍的机械请求。
- 大名单先入队，让队列分几天跑完，别指望一个晚上把全网黄推清零。

机制细节见 [`BLOCK_SAFETY.md`](BLOCK_SAFETY.md)。

## 常见问题（FAQ）

**为什么是拉黑，不是本地隐藏？**
本地隐藏纯属鸵鸟战术：只骗过了你自己这一个电脑屏幕，一换手机 App 打开推特，满屏黄推依然骑脸；更尴尬的是，对方依然可以肆无忌惮地 @ 你、私信你、在你的推文下欢快开 party。X 原生 Block 则是物理级超度：全端同步清空，对方从此在你的世界里彻底断连。

**会封我自己的推特账号吗？**
我们比你更怕被封号，所以给插件套上了三层防弹衣：24 小时 400 发子弹限额、拟人化时间抖动、以及遭遇推特 429 报错时后台立刻装死休眠的熔断机制。宁可慢一点，绝不拿你的大号去推特风控枪口上试探。

**需要 X 开发者 API 或 OAuth 应用授权吗？**
完全不需要。拉黑直接通过你在浏览器里已登录的 X 会话执行，FeedSieve 服务器连你的账号密码长什么样都不知道。

**我的推文会被上传吗？**
绝对不会。推文原文不出设备是绝对红线。内容分析全在本地算哈希指纹；社区上报只包含 handle / 分类 / 话术指纹哈希 / 外链域名，绝无任何浏览历史。完整口径见 [PRIVACY.md](https://github.com/realchendahuang/feedsieve/blob/main/PRIVACY.md)。

**手滑拉错人，或者正常博主被误标了怎么办？**
- 如果是你手滑拉错：在已拉黑列表里点「放回来」，原生 Unblock 一秒捞回原路放生；
- 如果是正常博主被误标：页面点「误标？」直接加入本地白名单；如果进了社区候选，博主本人或粉丝去[官网申请入口](https://feedsieve.win/lists/apply)递交申诉，社区抢救票生效后秒级随签名快照全网豁免出狱。

**换马甲改名字了还能识别吗？**
能。黄推换马甲不换话术（模板哈希指纹追踪）、换号不换域名（外链落地页域名关联分析）。道高一尺魔高一丈。

**白名单有几种？**
两种：社区「验证正常」白名单（净抢救票 ≥3，与黑名单镜像，随签名快照下发、一票豁免）与维护者维护的[推荐白名单](https://github.com/realchendahuang/feedsieve/blob/main/community/lists/whitelist.yaml)（人工筛选的知名正常博主）。两者都绝对不标注。

**支持 Firefox / Safari / 移动端吗？**
Edge / Brave 等 Chromium 浏览器直接从 Chrome 应用商店安装即可。移动端和 Safari 暂时没有排期，当前精力聚焦把 Chrome 版的稳定性和打野手感拉满。详细取舍见 [`VISION.md`](VISION.md)。
